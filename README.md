## OpenAI (ChatGPT) integration

Setup:

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
cp .env.example .env   # then fill in your OPENAI_API_KEY
```

Run:

```bash
.venv/bin/python chat.py "Say hello in one sentence."
```
